# vangel's own half-width glyphs for translated text, drawn to match the game's 8x16 font
# (tools/vgfont.py merges them into the pack's "latin8"; docs/translation.md). The game's font
# itself is not here: it is read from the player's M.EXE when the pack is built.
#
# Conventions of that font: 8x16 cells, '#' = ink, strokes one pixel wide (the engine
# emboldens one pixel to the left at run time, as the game does), capitals rows 3-13,
# lower case rows 6-13, the baseline row 13, descenders rows 14-15; nothing in column 0 (the
# emboldening would not widen it).
#
# Two kinds of block, each "U+XXXX <char> <note>" then 16 rows:
#   a glyph of its own        the whole cell
#   "mark on X"               only the mark (an accent, a dot, an ogonek, a stroke): the
#                             letter is the game's own glyph of X with these pixels added
# Edit freely: this file is the source, nothing regenerates it.
